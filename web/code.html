CODE WORKBENCH.

Eine vollständige lokale VS-Code-ähnliche Entwicklungsumgebung für KOR-NEXUS und deine Spielprojekte. Der Editor läuft als eigener lokaler Dienst; KOR-NEXUS selbst bleibt davon unabhängig nutzbar.

01 / RUNTIME CHECK

IDE-STATUS

Die IDE wird nur auf ausdrücklichen Klick gestartet und bindet ausschließlich an 127.0.0.1.

code-server fehlt.
Installiere auf Arch Linux ein vertrauenswürdiges code-server-Paket (z. B. aus dem AUR), prüfe den Paket-Maintainer und starte KOR-NEXUS danach neu. KOR-NEXUS installiert keine zusätzlichen Programme automatisch.

03 / WORKFLOW

ENTWICKLUNGSABLAUF

01 — EDIT

Code, Konfigurationsdateien und Dokumentation im vollständigen Editor bearbeiten. Terminal und Erweiterungen stellt code-server bereit.

02 — VERIFY

Tests und Build-Kommandos im integrierten Terminal ausführen. Fehlermeldungen prüfen, bevor Änderungen übernommen werden.

03 — REVIEW

Git-Änderungen kontrollieren. KOR-NEXUS führt weder automatisch Commits noch Pushes oder Merges aus.

Sicherheit: Der IDE-Dienst ist nur an die lokale Loopback-Adresse gebunden. Verwende keine öffentlich erreichbare Bind-Adresse. Zugangstokens gehören in sichere lokale Anmeldedaten und niemals in Quellcode oder Commits.
